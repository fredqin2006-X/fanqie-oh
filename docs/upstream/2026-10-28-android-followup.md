## 平台差异

- 最低 HarmonyOS 6.1 / API 23、bundle ID、HUKS 加密密钥和既有数据保护机制保持不变。
- 鸿蒙使用实际系统画中画能力，不移植 Android 悬浮窗权限；音频变速设置只展示鸿蒙可用的系统引擎，不提供无法生效的 Android Sonic/AudioTrack 选项。
- Android 的 HyperOS 公平内存广播、特定墨水屏硬件刷新、JNI/R8/armeabi-v7a 构建配置属于平台专用实现。共享内存/阅读逻辑和墨水屏视觉模式已合入，鸿蒙没有对应硬件能力时不虚报支持。
- Android CryptoNative.kt 的 Windows JVM realpath 修复没有机械移植；鸿蒙 harmony_media.rs 原有 canonicalize、沙箱包含性和 capability 校验继续保留。
- 上游共享 Dart 中的 Windows 分支和源码依赖保留以维持编译关系，鸿蒙不会初始化 Windows 媒体、窗口或登录插件。
- 品牌仍为番茄OH。上游作者的支持入口保留原布局并明确署名“上游作者”。实现阶段未指定新发布版本；用户测试通过后授权以 [v1.2.0](../releases/v1.2.0.md) 发布。
