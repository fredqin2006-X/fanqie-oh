# 2026-10-28 横屏播放器手势

本轮按用户要求同步安卓新增功能，在安卓新版播放器布局上补齐鸿蒙横屏手势。
保持 HarmonyOS 6.1 / API 23 最低支持配置。

## 交互

| 操作 | 行为 |
| --- | --- |
| 长按视频 | 临时 2 倍速，显示提示；松手、取消、切换播放器或离开前台后恢复原倍速 |
| 双击左/右三分之一 | 快退/快进 10 秒，限制在有效时长内；连续操作累计 |
| 双击中间三分之一 | 暂停/继续播放 |
| 横向滑动 | 以当前进度为起点预览，横跨整屏最多调整 120 秒；松手后定位，取消不定位 |
| 左半屏上下滑动 | 临时调整当前窗口亮度，显示百分比；退出全屏、切换播放器或离开前台后恢复原值 |
| 右半屏上下滑动 | 调整当前播放器音量，不修改系统音量与默认静音偏好 |

横屏支持分区双击和滑动，保留安卓新版分屏的滑动手势。全屏以视频和弹幕为主，反馈短暂出现。
单击显示/隐藏控件，中间双击暂停/继续；返回退出全屏，竖屏翻集、面板和锁屏行为沿用安卓实现。
亮度会话独立于阅读会话，保存并恢复窗口原值（包括跟随系统的 `-1`）。
