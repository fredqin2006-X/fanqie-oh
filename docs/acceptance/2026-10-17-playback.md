# 2026-10-17 播放黑屏修复与复测范围

本轮针对“刚进入短剧就是黑屏”，使用 DevEco Pura 90 Pro 的 HarmonyOS 7 / API 26 x86_64 模拟器排查。修复源码提交为 `49fc140`。没有据此认定 HarmonyOS 6.1 / API 23 ARM64 真机通过。

## 复现与修复

普通冷启动进入短剧后，播放器可报告 prepared、firstFrame 和递增进度，但视频区持续黑色。明确的 Surface 创建回调和原生窗口挂载均成功，不能用这些回调替代可见画面证据。

- ArkUI TEXTURE / Flutter 外部纹理路径在该模拟器上持续黑屏；直接写入 RGBA 缓冲区同样不能解决显示问题。
- 恢复原生 DISPLAY / SURFACE 可出图，但选集弹层被视频矩形裁剪，切集后出现 EGL_BAD_SURFACE。所用 IJK SDL 的输出释放代码会终止共享默认 EGLDisplay。
- 最终保留 FFmpeg 软件解码，替换 IJK 的 SDL 输出：原生端仅保存最新 RGBA 帧，由 Flutter 上传并绘制图像。避开原生纹理导入、平台视图切片和 IJK 的 EGL 释放；不修改原短剧页面的布局与控件。原生帧生产与读取通过互斥锁同步，不积压历史帧，Widget 同时只执行一个上传请求并在释放后丢弃迟到图像。
- 原生 AVPlayer 仍优先使用；仅在既有不支持编码的错误条件下进入软件 fallback。最低支持版本没有下调。
