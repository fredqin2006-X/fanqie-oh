# 2026-10-17 强制横屏与默认分辨率

后续用户确认本包强制横屏仍失败；方向调用队列和旋转后额外边距的复现、修复及模拟器证据见 [后续复测](2026-10-17-emulator-rotation.md)。

用户真机反馈：横版视频点击“全屏观看”后仍不能横屏。此前 Widget 测试验证了方向请求，不能证明手机窗口已经旋转；该反馈仍作为未通过项，等待本包复测。

## 改动

- 在“全屏观看”旁增加“强制横屏”。它直接进入全屏并固定横屏，不依赖视频尺寸；迟到的尺寸事件和后续连播不能覆盖手动选择。通用播放器全屏按钮旁也提供旋转入口，窄屏下控件可收缩。
- 鸿蒙方向请求经 `fqapp/display` 直接取得主窗口，调用固定 `LANDSCAPE` / `PORTRAIT` 策略；退出或销毁后恢复进入全屏前的窗口方向策略。系统栏设置独立处理，失败不会跳过方向请求；方向失败会给出提示。
- 全屏只留画面及已启用弹幕，返回先退出全屏；原有开孔安全区适配保持有效。
- “设置 → 短剧 → 默认分辨率”提供最高可用、2160P、1440P、1080P、720P、540P、480P、360P。未设置时默认最高；没有指定档位时选择该集最高档。设置会持久化，并用于推荐流及完整播放页的新播放请求。
- 匹配分辨率优先采用档位标签，避免把竖屏 720P 的像素高度 1280 误读为画质档位；档位地址和对应解密密钥一起切换。当前集的手动画质选择优先于全局默认，且按剧集 id 保存到当前会话。单流与已缓存离线视频沿用唯一可用地址。

## 验证

- 107 项相关 Flutter 测试全部通过，修改文件静态分析无问题。覆盖普通/直接全屏、横竖片源、未知尺寸、手动横屏后迟到尺寸与播放器替换、系统栏失败、返回恢复、窄屏与大字体、开孔区域，以及分辨率设置重开保存、推荐流/完整页选流、缺档和默认最高、手动覆盖及密钥一致性。
- 本轮不声称新增原生运行或真机验收；这些主机测试不能证明物理屏幕已旋转。最低版本保持 HarmonyOS 6.1 / API 23，ARM64 Release 未签名包供用户沿用 DevEco 研发签名后复测。
- ARM64 Release 构建 `20261017T021719705Z-cf8b7f` 成功；已核对打包版本、debug=false、min/target API 23 和 ARM64 应用/引擎/播放器 ELF。交付文件和摘要见 [交付说明](../delivery.md)。
