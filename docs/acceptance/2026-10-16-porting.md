原 `main.dart`、`pages/`、`widgets/` 直接复用，共 90 个文件；89 个归一化文本一致，`listen_mode_page.dart` 仅增加 `player.audioOnly = true` 平台接缝，不改布局、绘制或交互。67 个资源中 66 个 SHA-256 一致，`assets/web/index.html` 仅删除一个空白行上的空格。`tools/verify-upstream-ui.ps1` 只读参考目录并复核这些精确例外。原品牌图用于鸿蒙启动/桌面资源。`app_theme.dart` 与 vendored UI 库仅为 OHOS 选择既有 Android 分支。

没有新增产品页面。早期 G1 临时页面已删除。`test_driver/harmony_acceptance.dart` 是显式 debug 验证入口，启动原应用并通过已认证的 Dart VM service 提供非可视测试命令；正常 main/release 不包含该入口。静态文件一致并不代表双端逐像素视觉验收已经完成，仍需在相同字号、主题和屏幕规格下对照安卓截图。

## 实现要点与复现

`SecureKeyPlugin` 使用不可导出的 HUKS AES-256-GCM 根密钥、随机 nonce 和条目名 AAD 包装 Hive/设备池密钥。已有坏密钥、坏密文或 HUKS key 丢失时保留数据并失败，不用明文/空库掩盖故障。

`harmony_media.rs` 复用原 C CENC 核心，通过本地 capability URL 向 AVPlayer 提供按需解密 MP4。校验上游 206/Content-Range、限制单次缓冲、会话数量与缓存，销毁/核心退出取消流。原 C 读取可能在 atom 边界短读，包装层循环补齐已承诺的 HTTP 范围。使用 Flutter `registerTexture(getTextureId())`，不调用该引擎尚未实现的旧纹理创建/释放路径。

后续发现模拟器在纯音频退后台、回前台后释放无用视频纹理时黑屏；冷启动和普通前后台对照正常。音频改为不分配视频 Surface，音频控制器及旧听书页只传递非可视 `audioOnly` 标记。修复后加密 AAC 退后台、返回、销毁，原首页截图正常；视频 CENC 首帧/销毁复测正常，25 个受影响 Dart 用例通过。该修复不等于视频后台/所有 GPU 生命周期已全面验收。

每次 HAP 尝试的输入清单、结果和 SHA-256 见 `docs/builds/`，全部要求本地提交。私有 VM URI、capability、日志、截图、构建物均留在忽略目录。本次 H.264/CENC、TTS、AAC 和文档验证由显式 debug 入口执行；正常产品构建使用 `lib/main.dart`。

```powershell
./tools/verify-upstream-ui.ps1
. ./tools/environment.ps1
Push-Location app
flutter analyze --no-pub
flutter test --no-pub
Pop-Location
./tools/build-native.ps1 -Target ohos-arm64
./tools/build-hap.ps1 -Target ohos-arm64 -Mode release
# 审查差异、补充构建记录，显式暂存本轮文件并本地提交后，才可再尝试 HAP。
```

TTS 参数依据 [Huawei Core Speech Kit API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references-V13/hms-ai-texttospeech-V13) 与安装 SDK 类型声明；文档选择基于 [系统 Picker](https://developer.huawei.com/consumer/cn/doc/HarmonyOS-Guides/use-picker)。实现只使用不晚于 API 23 的应用接口。
