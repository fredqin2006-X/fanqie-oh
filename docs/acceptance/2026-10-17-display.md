# 2026-10-17 全屏与开孔适配

## 用户人工真机反馈

用户对上一播放修复版反馈：播放、漫画、阅读、听书正常，后台保活通过。这是用户报告的真机结果；不扩展为全部平台、所有异常情况或本轮新界面的验收。

## 本轮改动

- 全屏仅显示视频与已启用的弹幕；标题、播放底栏、进度条、选集、锁按钮、倍速提示及恢复按钮均隐藏。单击仍可暂停/恢复，但不会唤出控件；系统返回先退出全屏，保留播放页。
- 推荐流全屏按钮与选集弹层“全屏播放”直接进入此模式；普通剧集目录进入播放页仍保留常规控件。
- 根据解码后视频宽高，全屏分别固定为单一竖屏或横屏策略；未知尺寸时不猜测朝向，尺寸到达后再锁定；退出/销毁恢复原自动方向策略。
- 原生获取窗口 TYPE_CUTOUT 避让区域并监听 avoidAreaChange、windowSizeChange；保留开孔与屏幕边缘之间的空隙，按 Flutter 实际密度转换尺寸。旋转、窗口变更及回到前台都会刷新。
- 在根 Navigator 外物理预留安全区并裁剪内容，统一保护自定义标题、弹层、阅读、视频与弹幕；与现有 SafeArea 合并取最大值，消费已预留的 inset，避免重复留白。原生结果暂不可用时保留 Flutter 的安全边距及 cutout display feature 兜底。
- 预留区域使用当前页面背景；视频/短剧与阅读背景单独注册，隐藏 tab 不会污染其他页面背景，返回页面恢复对应背景色。设置等普通页面沿用应用主题画布色。

接口方案参考 [华为开孔避让说明](https://developer.huawei.com/consumer/cn/doc/doccenter-dev-faq/faqs-arkui-1089)，声明与本地 API 26 SDK 核对；最低兼容仍为 HarmonyOS 6.1 / API 23。

## 验证边界

最初 53 项相关 Flutter 测试通过；补齐直接全屏入口并扩大回归后，87 个相关用例通过（扩大运行中 86 项通过，1 项旧评论按钮期望按新需求修订后单独复测通过）。新增覆盖直接进入/手动切换、竖屏/横屏、通用视频/短剧全屏隐藏、弹幕保留、返回退出、像素密度转换、旋转后的侧边开孔、开孔上方间隙、背景恢复。源文件与新测试的分析无问题。原生窗口桥已通过 x86_64 与 ARM64 HAP 编译。

模拟器覆盖安装及运行捕获的组合命令被自动审批以 blocked by policy 拒绝，没有具体理由；未重试该动作。本轮不声称新增模拟器运行或真机通过。ARM64 Release 包供人工复测，签名要求与包摘要见交付说明。

重点复测：横屏与竖屏片源全屏只留视频/弹幕；返回手势先退全屏；转动手机不能改变被锁方向；设置标题、阅读标题与弹幕避开开孔；横屏开孔侧的视频完整可见；返回、切换主题/阅读底色后预留区颜色一致。
