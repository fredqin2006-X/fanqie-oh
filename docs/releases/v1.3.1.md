# 番茄OH v1.3.1

发布日期：2026-11-15。显示版本 **1.3.1**，构建号 **130**，bundle ID `com.fqapp.harmony.fqapp`，最低 **HarmonyOS 6.1.0（API 23）**，ARM64 发布包。

## 更新内容

- 修正宽屏平板排行榜书架的首屏定位：窗口宽度增加时，选中书从居中平滑移向左侧安全区，排行榜书脊利用横向空间展开。手机宽度保持原有居中行为。
- 保留 v1.3.0 已发布的 Android v1.0.204 图片加载超时与重试适配。

## 验收与构建

- `home_rank_shelf_geometry_test.dart`：8 项通过，覆盖手机、平板、超宽窗口、短屏和大字体布局。
- HarmonyOS API 26 x86_64 平板模拟器（2800x1840 px，密度 2.25，即 1244x817 dp）：静音后实测首页，16 本排行榜书横向展开；翻页从 01/16 到 02/16 并返回 01/16。`AudioPolicyService` 在操作前后均报告 MUSIC 音量 0、mute 开启。
- 模拟器安装并交互验证的是 x64 调试 HAP。ARM64 发布 HAP 未在该模拟器安装，也未在 HarmonyOS 6.1 ARM64 真机安装验收。
- ARM64 HAP 包内版本为 1.3.1（130），`minAPIVersion` 和 `targetAPIVersion` 均为 60100023，编译 SDK 为 26.0.0.105；16 个 `libs/arm64-v8a` 本地库均为 AArch64 ELF。
- 两次 HAP 构建记录：[x64 模拟器包](../builds/20261115T043227367Z-57c61b-debug-ohos-x64.md)、[ARM64 发布包](../builds/20261115T044528941Z-3ce8cd-release-ohos-arm64.md)。
