# 番茄OH v1.3.2

发布日期：2026-11-15。显示版本 **1.3.2**，构建号 **131**，bundle ID `com.fqapp.harmony.fqapp`，最低 **HarmonyOS 6.1.0（API 23）**，ARM64 发布包。

## 更新内容

- 短剧缓存任务遇到可重试的网络或取流错误时，等待 5 秒后自动重试，最多额外重试 3 次。重试期间显示次数；暂停或取消会中断等待。手动继续会重新开始重试计数。
- 延续 v1.3.1 的缓存播放修复：边看边缓存默认关闭，处理明文本地缓存播放、缓存完整性校验及播放失败后的在线回退。

## 验收与构建

- 用户于 2026-11-15 确认 v1.3.1 缓存播放修复已通过真机复测；未提供设备型号、系统版本及逐项结果。
- v1.3.2 新增的自动重试行为尚未单独进行真机验收。
