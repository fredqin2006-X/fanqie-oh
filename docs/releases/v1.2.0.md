# 番茄OH v1.2.0

发布日期：2026-10-28。显示版本 **1.2.0**，构建号 **127**，bundle ID `com.fqapp.harmony.fqapp`，最低 **HarmonyOS 6.1.0（API 23）**，面向 ARM64 手机。

## 更新内容

- 同步安卓 `1.0.133+138` 的新版首页、分类、OLED 主题、评论图片和统计界面，保留番茄OH品牌与鸿蒙适配。
- 阅读新增九宫格点击区、仿真翻页、文本替换、缓存续读及音量键翻页。
- 听书同步句级高亮、字幕、离线音频、连播、跳过头尾及 0.5–3.0 倍速，适配鸿蒙排队 TTS。
- 短剧同步分屏、侧面板与选集布局，新增自动缓存、下载画质、跨集画质记忆、解码器选择和系统画中画。
- 横屏播放支持长按临时 2 倍速、左右双击快退/快进 10 秒、中间双击暂停/继续、横滑定位及竖滑调亮度/播放器音量。
- 增加官方登录窗口、账号书架/历史采集与导入、采集分卷恢复和 ZIP 导出；修复登录关闭异常、迟到页面回调和原生安全区问题。
- 同步密文视频缓存、设备池并发、请求取消/超时、API v1 与局域网服务更新，保留鸿蒙媒体能力令牌和数据保护。

完整实现范围及平台差异见 [安卓更新同步记录](../upstream/2026-10-28-android-followup.md)。保留原 bundle ID、数据格式和既有密钥，构建号从 126 递增为 127。
