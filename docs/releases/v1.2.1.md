## 更新内容

- 修复听书期间阅读页不自动跟随、字幕与阅读位置不同步；支持播放/恢复自动跟随、手动翻页后回到原进度、跨章定位及真人录音关联原著。
- 更新本地安卓参考至 `1.0.201+206` / `c29b279`，同步书架分组、书旗书源、主题、AI 阅读及后端兼容改进。
- 补齐鸿蒙听书起播位置恢复、播放器画中画 owner 生命周期、后台播放交接与 HUKS 加密的 AI 凭据存储。
- 保留鸿蒙品牌、原 bundle ID 和数据格式；最低系统继续为 HarmonyOS 6.1 / API 23。

实现差异见 [安卓同步记录](../upstream/2026-11-08-android-followup.md)。
